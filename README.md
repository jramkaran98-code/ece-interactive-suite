# ECE Interactive Suite

An interactive web application containing a collection of tools for exploring concepts in **Electrical and Computer Engineering**.

The project combines number-system conversion, signal visualization, logic gate operations, and binary arithmetic into a single browser-based application.

## Features

### Universal Number Converter

Converts numbers between:

* Binary
* Decimal
* Hexadecimal
* Octal

The converter validates the input according to the selected number system.

### Signal Visualizer

Displays animated waveforms using the HTML Canvas API.

Users can adjust:

* Wave type
* Frequency
* Amplitude
* Phase

Supported waveforms:

* Sine
* Square
* Triangle

The visualization can also be paused and resumed.

### Logic Gate Simulator

Simulates basic digital logic gates using binary inputs.

Supported gates:

* AND
* OR
* NOT
* XOR

The application calculates and displays the resulting output.

### Binary Arithmetic Calculator

Performs arithmetic operations on binary numbers.

Supported operations:

* Addition
* Subtraction
* Multiplication

Results are displayed in:

* Binary
* Decimal
* Hexadecimal
* Octal

## Technologies Used

* **HTML5** - Application structure
* **CSS3** - Styling and layout
* **JavaScript** - Application logic and interactivity
* **HTML Canvas API** - Signal visualization
* **GitHub Pages** - Web hosting
